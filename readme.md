# shpscan

Анализ файлов регистратора `.shp` с прессов и прокатного стана: один файл — один цикл работы машины.
Программа читает файл, считает показатели цикла, строит графики и ищет отклонения от нормы по архиву.

Написана на Go, без сторонних библиотек. Собирается в один exe, работает без интернета.

## Что умеет

- **Просмотр в браузере.** Выбор одного или нескольких файлов (или целой папки), графики любых сигналов,
  сравнение циклов на одном графике, курсор со значениями, приближение участка мышью.
- **Отчёт по одному циклу.** HTML-файл с графиками, показателями и таблицами по всем сигналам.
- **Сводка по папке.** Норма каждого показателя (медиана и разброс), циклы с отклонениями, дрейф
  показателей со временем, таблица `cycles.csv` для Excel или pandas.
- **Все сигналы.** По каждому аналоговому сигналу — минимум, максимум и среднее; по каждому дискретному —
  время во включённом состоянии и число включений.
- **Несколько машин.** Машина определяется по сигналам файла, норма считается отдельно для каждой машины
  и операции (`_OP1_`, `_OP2_` в имени файла).

## Сборка

Нужен Go 1.20 или новее.

```
git clone https://github.com/KudinovArtemilus/shpscan.git
cd shpscan
go build
```

Сборка под 32-битную Windows:

```
set GOOS=windows
set GOARCH=386
go build
```

## Запуск

```
shpscan                          просмотр в браузере (http://127.0.0.1:8765)
shpscan файл.shp                 отчёт по одному циклу -> файл.html
shpscan -out D:\reports D:\shp   сводка по папке с подпапками -> report.html и cycles.csv
```

| Флаг | По умолчанию | Назначение |
|---|---|---|
| `-out` | текущая папка | куда писать отчёты |
| `-tz` | `5` | смещение местного времени от UTC в часах (для времени старта и смены) |
| `-addr` | `127.0.0.1:8765` | адрес страницы просмотра |
| `-all` | `true` | считать показатели по всем сигналам; `-all=false` — только по спискам профиля |

Страница просмотра по умолчанию доступна только с того же компьютера. С адресом `0.0.0.0:8765`
она откроется и с других машин сети, но пароля в программе нет.

`cycles.csv` записан с разделителем `;` и десятичной запятой. В pandas:

```python
pd.read_csv("cycles.csv", sep=";", decimal=",")
```

## Как считается норма

- Норма показателя — медиана по всем циклам группы, разброс — робастная оценка (1,4826 × MAD).
- Отклонение — выход за 3,5σ для основных показателей и за 6σ для показателей по всем сигналам.
- Норма считается от 10 циклов в группе, дрейф (последняя треть циклов против первой) — от 30.
- Показатели, которые от цикла к циклу только растут (счётчики), в норму не идут.

Пороги подобраны предварительно и требуют проверки на большом архиве.

## Формат файла .shp

Формат восстановлен по образцам файлов, официального описания нет. Все числа little-endian.

| Смещение | Содержимое |
|---|---|
| `0x000` | заголовок, 892 байта |
| `0x008` | время старта записи, Windows FILETIME (UTC) |
| `0x010` | количество дискретных сигналов |
| `0x02C` | количество аналоговых сигналов |
| `0x37C` | таблица имён: по 256 байт на сигнал, строка до нулевого байта |
| далее | отсчёты подряд: `uint32` время в мс, биты (по одному на сигнал), `float32` на каждый аналоговый сигнал |

Имена сигналов обрезаны регистратором до 31 символа. Единиц измерения в файле нет.

## Устройство кода

| Файл | Что в нём |
|---|---|
| `shp.go` | чтение формата `.shp` |
| `profile.go` | профили машин: списки сигналов для показателей и графиков, без логики |
| `kpi.go` | расчёт показателей одного цикла |
| `batch.go` | обработка папки, норма, отклонения, дрейф, CSV |
| `report.go` | HTML-отчёты с графиками SVG |
| `serve.go`, `ui.html` | просмотр в браузере |
| `main.go` | командная строка |
| `shp_test.go` | тесты (`go test`) |

### Как добавить машину

В `profile.go` описать новый `Profile`: сигнал, по которому машина узнаётся (`Detect`), сигнал усилия
(`LoadSignal`), списки сигналов для показателей и графиков — и добавить его в `Profiles`.
Файлы неизвестных машин тоже открываются: графики и показатели по всем сигналам работают без профиля.

## Ограничения

- Формат проверен на файлах трёх машин; у других версий регистратора он может отличаться.
- Нормы и пороги проверены на небольшом числе циклов.
- В режиме просмотра выбранные файлы копируются во временную папку и удаляются при выходе по Ctrl+C.
